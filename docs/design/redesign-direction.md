# FraterAI: knowledge in practice

The five user-supplied mockups pin the visual world. Seed 0ffeb31a was evaluated; its unrelated alternative worlds do not replace this explicit direction. Native CSS and Motion implement an editorial aesthetic, not an official institutional design system.

## First viewport
Paper background; preserved FraterAI mark with blue serif wordmark; one-line navigation; large left-aligned serif production-AI statement; original blue library engraving bleeds right and bottom; interactive operating-model card overlays the artwork. The mockup's long headline, blue eyebrows, square cards, and light-only print language are intentional user-reference exceptions to generic skill defaults.

## Visitor path
Understand the offer, explore capabilities, recognize your team's workflows, assess production controls, understand the process, contact the team. Six main landing sections, with platform principles inside capabilities and a compact audience navigation strip beneath the hero.

## Motion opportunities
| Location | Before | After | Purpose / frequency |
| --- | --- | --- | --- |
| Hero | Background video loop | One 1000ms illustration entrance, 650ms text entrance with 50ms stagger, 750ms model entrance after 100ms | Hierarchy / page mount |
| Operating model | Absent | Clickable stages; 180ms content crossfade, 280ms zero-bounce selection spring | Explanation / occasional |
| Navigation | Hover-only menu | Explicit disclosure, origin-top 180ms entrance, immediate keyboard response | Orientation / occasional |
| Buttons | Inconsistent response | 120ms press scale .98, 180ms arrow translation 3px on precise pointers | Feedback / occasional |
| Process | Repeated moving photos | Selected process detail with 220ms opacity transition | Explanation / occasional |

Rejected: looping KPI counters (fictional proof); constantly floating buildings (distracts from reading); magnetic form controls (hinders accurate input). Reduced motion keeps content visible, removes transforms, and uses instant keyboard states. Oil Motion's semantic video pipeline is unavailable because ZenMux is unconfigured; geometric/state motion is implemented directly, without claiming generated video.

## Composition and behavior
Desktop hero split, four-column service taxonomy, four-person audience cards, split enterprise controls, horizontal process rail, architectural closing invitation. Mobile explicitly stacks grids; process tabs scroll horizontally; menus fit the viewport with accessible dismiss/escape and focus handling. Source default content remains visible without JavaScript.

## Evidence
Existing site copy is authoritative for capabilities. Reference quotes, portraits, and metrics are not presented as real endorsements. Dashboard is explicitly an illustrative, user-operated workflow model. Contact field names/order and server integrations stay intact.
